Historical 2D diagnostics or full-fermion Nighthawk?

Review clarification, 19 October 2026: the old one-step number_preserving_t_only route is not the later 72-mode Nighthawk experiment. It omits diagonal hopping and nonlocal fermionic parity strings; onsite gates have no ideal U-dependent effect in that one-step run. The later network retains t, t-prime and U.

Runbook

Run paths from the repository root

Prepare the default 6x6 target

.\scripts\run_cuprate_2d_pipeline_wsl.ps1

Builds the curated 6x6 target configuration and core planning artifacts under results_cuprate_2d/.

Run the validation ladder

.\scripts\run_cuprate_2d_validation_ladder_wsl.ps1

Runs the staged local ladder for 2x3, 3x3, 4x4, and 6x6 step-1 validation snapshots.

Local baselines and comparisons

.\scripts\run_cuprate_2d_tdhf_wsl.ps1
.\scripts\run_cuprate_2d_gaussian_wsl.ps1
.\scripts\compare_cuprate_2d_observables_wsl.ps1

Generates TDHF, Gaussian/free, and same-observable comparison data for interpretation.

3x3 exact and hardware diagnostics

.\scripts\run_cuprate_2d_3x3_validation_wsl.ps1
.\scripts\run_cuprate_2d_3x3_exact_sector_baselines_wsl.ps1
.\scripts\compare_cuprate_2d_3x3_observables_wsl.ps1

Uses exact small-rung baselines before interpreting IBM or Fire Opal results.

4x4 and 6x6 tensor routes

.\scripts\run_cuprate_2d_4x4_mps_shallow_t_only_wsl.ps1
.\scripts\run_cuprate_2d_6x6_layout_scout_wsl.ps1
.\scripts\compare_cuprate_2d_6x6_shallow_t_only_vs_mps_wsl.ps1

Keeps larger runs tied to MPS/layout evidence instead of reading hardware shots in isolation.

Submission scripts

.\scripts\submit_cuprate_2d_*.ps1

Scripts named submit_* can submit IBM Runtime or Fire Opal jobs. Treat them as live hardware actions.

The Windows wrappers resolve the repository root from their own location and call the known WSL Qiskit environment: /home/bram/.venvs/qiskit/bin/python.

Boundary

How to read the hardware results

Hardware output in this repository is diagnostic until it has been compared with the local baselines and observable-comparison files. The validated interpretation is narrower than a physics discovery claim: circuit behavior, noise, sector survival, and same-observable comparisons for a staged 2D Hubbard route.
